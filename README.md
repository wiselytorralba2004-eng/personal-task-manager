## Project Description

A simple Personal Task Manager built using Laravel. The system allows users to create, view, edit, delete, and update the status of tasks.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status
- Pending and Completed task status
- Due Date
- Task Description

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS

## Laravel Structure

The project follows:

Routes → Controller → Model → Database → Blade

## CRUD

- **Create** – Add Task
- **Read** – View Tasks
- **Update** – Edit Task / Update Status
- **Delete** – Delete Task
